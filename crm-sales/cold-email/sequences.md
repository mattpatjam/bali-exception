# Cold Email Sequences — Closio Estate

## Setup Notes

- Sending tool: Instantly.ai, Lemlist, or Mailshake (warm domain required)
- From name: Matthieu Jammers (personal — not "Closio Estate")
- From email: Use a warmed inbox on a separate domain (e.g. matthieu@closioestate.com)

## Reply Handling

| Reply type | Response |
|---|---|
| "Not interested" | Thank them, leave door open, ask if they know someone who might be |
| "Too expensive" | You haven't quoted a price yet — ask what budget they're working with |
| "We already have a CRM" | "Which one? I'm curious what's working well and what isn't" — gather intel |
| "Send more info first" | Send the EN brochure + closioestate.com link. Follow up in 3 days |
| "Call me" | Book via calendar link. Confirm 24h before |
| No reply to all 3 | Move to LinkedIn connection queue if not already connected |
