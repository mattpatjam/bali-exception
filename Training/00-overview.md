# Bali Exception — Sales Training Framework

**Who this is for:** new sales agents joining Bali Exception (Bali or Lombok office).

**What this is:** the full deal lifecycle, one file per stage, from first lead contact to referral. Each stage file has the technique (what to say, what to do) and a checklist at the end (what to verify before moving to the next stage).

**What this replaces:** informal, on-the-job training. Nothing was written down before this. If you're reading this as a new hire, you're the first person to go through it as a document instead of just shadowing Matthieu.

## How to Use This Framework: Document → Duplicate → Certify

This is Hormozi's employee training method (source: `.claude/knowledge/hormozi-advisor/knowledge/scaling.md`), applied stage by stage.

**Step 1 — Document.** The stage files are the checklist. If a new agent gets stuck or confused on a step, that's a gap in the file, not a gap in them, flag it so the file gets fixed.

**Step 2 — Duplicate.** For each stage: new agent reads the file, then shadows Matthieu (or a senior agent) running that stage live on a real lead or deal. Then the new agent runs it themselves while being observed. Roles reversed, same checklist.

**Step 3 — Certify.** Once a new agent runs a stage's checklist correctly on their own, they're certified on it. Move to the next stage.

**Grade on process, not outcome.** If they followed the checklist and the deal still didn't close (a lead ghosts, a viewing falls through), that's not a failure of the agent, it's normal deal attrition. If they skipped steps, that's the thing to correct. Judging by outcome alone means you can't tell whether the checklist is broken or the agent didn't follow it, so grade the follow-through.
